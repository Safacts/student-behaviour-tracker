Complete API Reference

Students API

GET /api/students

Get all students list

curl -X GET http://localhost:8000/api/students

Reports API

GET /api/report/{student_id}

Get comprehensive student report with AI recommendations

curl -X GET http://localhost:8000/api/report/S001

Common Issues & Solutions

API Not Responding

The API server is not responding to requests.

Solution:
1. Check if the service is running: python main.py
2. Verify port 8000 is not blocked
3. Check for any error messages in the console
<4 class="font-semibold text-amber-800 mb-2">AI Recommendations Not Working

AI reports are showing errors or not generating.

Solution:
1. Check Google API key: echo $GOOGLE_API_KEY
2. Verify API key is valid and not leaked
3. Check internet connection for AI service

Database Connection Issues

Cannot access student data or getting empty results.

Solution:
1. Check if behavior.db exists in the project directory
2. Verify database file is not corrupted
3. Test with: sqlite3 behavior.db ".tables"

Performance Issues

API responses are slow or timing out.

Solution:
1. Check system resources (CPU, Memory)
2. Restart the service: Ctrl+C and python main.py
3. Check for large database files affecting performance
